A chess engine in 3,460 bytes of Python: full legal move generation, negamax search with alpha-beta pruning, quiescence, a transposition table and piece-square-table evaluation, playing a fixed budget of 24,000 nodes a move — deterministic, no clock, no randomness. It plays each game through the make.fun env at MAKEFUN_ENV_URL.

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python3 main.py
```
